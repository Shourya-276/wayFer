WayFer Mobile Screenshots Directory
====================================

You can drop your actual high-resolution WayFer mobile app screenshots in this directory:
- screen-1.png (Choose destination / map screen)
- screen-2.png (Choose date & time / schedule)
- screen-3.png (Nearby matches / score list)
- screen-4.png (Message request / connect)
- screen-5.png (Chat / accepted match)
- screen-6.png (Meet / active ride pickup)
- screen-7.png (Ride / en-route trip view)
- screen-8.png (Done / trip completed)

The website automatically detects and loads these image files inside the 3D phone mockup!
If an image is not present, the interactive, high-fidelity vector screen simulation will render seamlessly.
